Insurance Churn Analysis - 
Exploratory data analysis project developed using Power BI, SQL and Excel, focused on early policy cancellation patterns in the insurance sector.

Background - 
This project was inspired by a real observation made during 7 years working in insurance operations: policies with a 3-month premium waiver campaign were being cancelled consistently at the 90-day mark. That pattern raised a question — are campaign-acquired customers more likely to cancel early?
The dataset used is fictional and was created for learning purposes. The analytical reasoning behind it is real.

Key Findings 
	•	Early cancellation rate (<90 days) was 9.0% for campaign-acquired customers vs 6.1% for non-campaign customers.
	•	Price was the most frequent cancellation reason among campaign-acquired customers.
	•	Cancellation behaviour varied across sales channels and product types.
  
Tools Used 
	•	Power BI - dashboard and visualisation
	•	SQL - data exploration and validation
	•	Excel - data preparation
