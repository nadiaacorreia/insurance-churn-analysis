# insurance-churn-analysis
Exploratory data analysis project developed using Power BI, SQL and Excel.

## Objective
Analyze the impact of commercial campaigns on early policy cancellations and identify churn patterns.

## Key Insights
- Customers acquired through campaigns showed higher early cancellation rates.
- Price-related cancellations were more frequent among campaign-acquired customers.
- Different sales channels showed different cancellation behaviors.

## Tools Used
- Power BI
- SQL
- Excel
